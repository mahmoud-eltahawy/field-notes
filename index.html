Field Notes

a log of coding in a low-spec, offline environment

The graph above is usually the first thing people ask about. It looks like a mistake: weeks of absolute silence, followed by intense blocks of activity, then silence again. It's not burnout; it's structural.

For a long stretch of time, my only machine was a 32-bit box with 4 GB of RAM running Windows 7. No network, no smartphone, no way to pull anything down. The cycle was roughly 21–28 days in that setup, then 8 days off, then back again.

I managed to get a few PDFs in beforehand: linear algebra notes, the MDN site source, and the Vim docs. That was the entire toolbox for the whole stretch.

I still had other work to do, so from the point of view of the people I was working under, programming was not the top priority of the day — I ended up practicing it on the side. For me it was the first priority.

The only language available in that environment was JavaScript. Nothing else would install. Everything below was written inside those constraints.

Note on transparency: Every project linked below was written entirely offline, without AI or external help. This home page is the only exception — I used AI to help structure and write it later.

What I built

All projects are plain JavaScript and run locally in the browser. Usage is kept brief; open one to try it.

  1. Breakout

    Break every rock without losing all balls.

    • Move the mouse left/right to control the paddle.
    • Some broken rocks drop gifts: extra balls or a temporary wider paddle.

  2. Game of Life — version 1

    Conway's Game of Life with a basic custom-config editor.

    • ← / → change generation speed.
    • ↑ / ↓ zoom.
    • R reset the current config.
    • Hold Ctrl and drag to pan.
    • Use the “add config” button to place cells with the cursor.

  3. Game of Life — version 2

    Conway's Game of Life with a richer custom-config editor.

    • P pause/resume.
    • H show help.
    • ← / → change speed, or cycle cursor patterns in add mode.
    • ↑ / ↓ zoom.
    • R reset.
    • A enter add-config mode.
    • G start playing the config you built.
    • Hold Ctrl and drag to pan.

  4. Console 2D Plot

    Plot JavaScript functions in a console-style 2D grid.

    • Type a function body, for example return x*x or return Math.sin(x).
    • Click GO to plot it.
    • Drag the canvas to pan.
    • Each plotted function has its own hide/show and recolor button.

  5. In-Place Memory Sorting Demo

    Visualize in-place sorting algorithms: bubble, selection, insertion, and quicksort.

    • Pick an algorithm from the dropdown.
    • Click Kick to run it.
    • Click Unsort to shuffle the bars again.

  6. Bezier Curves Demo

    Visualize Bezier curve construction.

    • Hold Ctrl and click to add a control point.
    • Hold Alt and drag to move a control point.
    • Replay restarts the drawing animation.
    • Pop removes the last control point.

  7. Explore Shaders with JS

    A per-pixel UV-to-RGB experiment: a rotating blackhole gradient written as a JavaScript function.

    • Purely visual; just open it and watch.

There were other projects, but they do not deserve publishing. They were closer to demos than projects — a demo like basic Trigonometry functions, for example.
